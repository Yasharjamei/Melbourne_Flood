# Urban Development Program 2017 and 2018 (open data)

Used by `pipeline/forecast/udp_backtest.py` to back-test the forecast's UDP step.

| File | Dataset | DataShare order |
|---|---|---|
| `MRS2017.zip` | Major Residential Redevelopments Sites 2017 | Order_BMJBQV |
| `BH2017.zip` | Broadhectare Residential Land 2017 | Order_Q7K8NV |
| `MRS2018.zip` | Major Residential Redevelopments Sites 2018 | Order_QR6BUJ |
| `BH2018.zip` | Broadhectare Residential Land 2018 | Order_E36ZML |

Source: Urban Development Program, Department of Transport and Planning (Victoria), via DataShare
(DEECA). Licence: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/),
as stated in each order. Kept as delivered (shapefiles, MGA2020 zone 55, with the custodian's PDF metadata).

Unlike these editions, UDP 2025 (used by the forecast) comes under a DEECA Data Access Licence and is
not stored here; see `data/static/udp2025/README.md`.
