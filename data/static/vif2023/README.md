# Victoria in Future 2023 (VIF2023)

Population, household and dwelling projections, Department of Transport and Planning, September 2023.
Source: https://www.planning.vic.gov.au/guides-and-resources/data-and-insights/victoria-in-future

Committed here because the source site refuses automated downloads (HTTP 403 to CI), so the pipeline
cannot fetch them. Files are unchanged from the publisher.

| File | Geography | Years |
|---|---|---|
| `VIF2023_LGA_Pop_Hhold_Dwelling_Projections_to_2036.xlsx` | 79 LGAs | 2021, 2026, 2031, 2036 |
| `VIF2023_LGA_Pop_Age_Sex_Projections_to_2036.xlsx` | 79 LGAs, five-year age by sex | 2021–2036 |
| `VIF2023_Regions_Pop_Hhold_Dwelling_Projections_to_2051.xlsx` | Metropolitan regions and Regional Partnerships | 2021–2051, five-yearly |
| `VIF2023_Regions_Pop_Age_Sex_Projections_to_2051.xlsx` | as above, five-year age by sex | 2021–2051 |

Values are rounded (LGA files to the nearest 10; region files to the nearest 1,000 or 100).
VIF is a projection, not a forecast or a target (the publisher's own wording).
